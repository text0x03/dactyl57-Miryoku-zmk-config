# Dactyl57 当前键位使用说明

本说明对应本仓库 `t03_dactyl57l.keymap`，固件基于 ZMK v0.3，主控为 nice!nano v2。左半区为主机侧，USB 数据线接左半区；右半区通过蓝牙与左半区通信。电脑蓝牙看到的键盘名称为 `text03 dactyl`。

## 1. 先记住这些操作

| 按键 | 短按 | 按住 |
| --- | --- | --- |
| 左拇指 Space（K44） | 空格 | NUM 数字层 |
| 左拇指 Esc（K45） | Esc | NAV 导航层 |
| 右拇指 Enter（K48） | 单次回车 | SYM 符号层 |
| 右拇指 Backspace（K49） | 删除前一个字符 | MOUSE 鼠标层 |
| 中间偏左 Tab（K16） | Tab | MEDIA 媒体层 |
| 中间偏右反斜杠（K17） | `\` | FUN 功能层 |

这些层键除 Enter 外使用 ZMK 默认 200 毫秒判定；Enter 使用独立的 300 毫秒判定，给正常短按留出更多时间，减少较慢的短按被误判为切层。按住层键进入对应层，松开回到原层。

**当前只有 NUM、NAV 和 GAME 配置了专用键位。SYM、FUN、MEDIA、MOUSE 全部透明，按住后仍沿用下层按键，没有符号、F1–F12、音量或鼠标操作。** `CONFIG_ZMK_POINTING=y` 只启用支持，不会自动生成鼠标键位。

## 2. Enter 修复后的用法

- 在 300 毫秒内按下并松开：发送一次 Enter，信号持续 40 毫秒后自动释放。
- 连续短按：每次产生一个 Enter；宏队列在相邻脉冲之间保留 10 毫秒间隔。
- 连续短按之后再按住超过 300 毫秒：进入 SYM；游戏层中进入 FUN，不应持续回车。
- Enter 使用“点按优先”：300 毫秒内与字母发生交叠也不会立即变成切层；需要层组合时，先按住 Enter 超过 300 毫秒，再按其他键。
- 长按 Enter 不提供自动重复回车；需要多个回车请多次短按。

这次修改针对回车信号的时长和释放方式，不代表已确认实机故障根因。必须刷入新固件并完成下方测试，才能确认短按漏响应和连击是否解决。

## 3. 基础层与修饰键

下表中的 `字母 / 修饰键` 表示短按输出字母，按住作为修饰键。`L` / `R` 是左右修饰键，GUI 在 Windows 上是 Win，在 macOS 上是 Command。

| 按键 | 按住功能 |
| --- | --- |
| A | 左 GUI |
| S | 左 Alt |
| D | 左 Ctrl |
| F | 左 Shift |
| J | 右 Shift |
| K | 右 Ctrl |
| L | 右 Alt |
| P、`/` | 右 GUI |

修饰键采用 balanced 判定、320 毫秒长按阈值。按住超过阈值可触发修饰键；阈值内的组合要求另一半区的按键按下并松开，才提前触发修饰键。同侧滚动输入优先按字母处理。最近一次普通键输入距今不足 150 毫秒时优先点按；同一双功能键在前一次按下后 175 毫秒内再次按下，也会优先点按。这些参数仅作用于 `hml` / `hmr`，不作用于 Enter。

常用例子：按住 D 再按右半区字母，实现 Ctrl 组合；按住 K 再按左半区 C / V / X / Z，实现 Ctrl+C / V / X / Z。若刚结束快速打字，先停顿约 150 毫秒再开始修饰键组合。

## 4. NAV 导航层

按住左拇指 Esc（K45），再按下列基础层位置。松开 Esc 返回基础层。

| 基础层位置 | NAV 功能 |
| --- | --- |
| H | Caps Lock |
| J / K / L | 左 / 下 / 上方向键 |
| P | 右方向键 |
| `/` | End |
| N | Insert |
| M | Home |
| 逗号 / 句号 | Page Up / Page Down |
| Enter | Delete（可长按重复删除） |
| Backspace | 普通 Backspace（可长按重复） |
| A / S / D / F | 直接作为左 GUI / Alt / Ctrl / Shift |

例如：按住 Esc 后按 J 向左移动；按住 Esc 后按 Enter 删除光标后面的字符。其余位置透明，保留基础层行为。

## 6. GAME 游戏层

进入方式：按住 Space 进入 NUM，再按 N36。GAME 会保持激活，松开 Space 后仍在 GAME。

退出方式：按 N36，发送一次 Esc，然后切回 BASE。

**N36 是矩阵第 3 行、左半区最靠内的第 6 列（从 0 计数），位于 B 的右侧；它在基础层被禁用。仓库没有准确的 57 键实体坐标图，若键盘上没有这个位置，当前 GAME 入口和出口无法通过实体按键使用，需要另选一个实体位置后修改。**

GAME 的字母均为普通按键，不带字母区长按修饰。Enter 仍然短按单次回车、长按 FUN；Space、Backspace 是普通可重复按键。两个中间位置 N26、N27 也可按住 FUN，但 FUN 当前为空层。

## 7. 连接、电源与蓝牙

- 有线：用支持数据的 USB 线连接左半区；右半区需要正常供电，并与左半区完成内部配对。
- 蓝牙：左半区开机后，在电脑蓝牙设置中查找 `text03 dactyl` 并配对；右半区不需要单独与电脑配对。
- 这套键位没有分配“切换蓝牙槽位”“清除配对”“切换 USB / 蓝牙输出”快捷键，因此无法在键盘上直接操作这些功能。
- 闲置 30 秒进入空闲状态；闲置 30 分钟进入深度睡眠并断开蓝牙。按键唤醒后等待重连，若首键未输入，再按一次。
- 电量上报已启用；电脑是否显示左右电量取决于系统支持。

## 8. 获取并刷入新固件

1. 打开本仓库的 [Actions](https://github.com/text0x03/dactyl57-Miryoku-zmk-config/actions)，找到本次提交对应的 “Build ZMK firmware”，确认左右半区全部构建成功。
2. 在该次运行的 Artifacts 下载固件压缩包并解压。按文件名中的 `t03_dactyl57l_left`、`t03_dactyl57l_right` 区分左右固件；另一个 `settings_reset` 是清除设置用固件。
3. 将左半区通过 USB 数据线连接电脑，按照主控支持的复位方式进入 UF2 引导盘（nice!nano 通常是快速按两次复位）。将左半区 UF2 复制进去，等待自动重启。
4. 将右半区通过 USB 连接，按同样方法刷右半区 UF2，等待重启。更新完成后将数据线接回左半区，两边正常供电。
5. **常规更新不要刷 `settings_reset`。** 它会清除已存储的蓝牙设置。只有配对故障且确认需要重置时才使用；之后还要刷回正常固件，并在电脑端删除旧配对再重新配对。内部左右配对故障需要两侧都清除设置后再刷回各自正常固件。

本次按键逻辑由左侧主机执行；左右都刷同一批构建产物，可以避免两侧版本不一致。构建成功只代表固件编译通过，不能替代实机验证。

## 9. 更新后的检查清单

建议先用 USB 连接，在空白文本编辑器里测试，再断开 USB 测蓝牙。

| 操作 | 预期结果 |
| --- | --- |
| Enter 短按 10 次，每次间隔约 200 毫秒 | 正好 10 个换行 |
| Enter 快速短按 3 次，随后按住 2 秒 | 只有前面 3 个换行；按住期间不继续换行 |
| Enter 单独按住 2 秒再松开 | 不换行，松开后继续正常输入 |
| Enter 短按一次，松开后输入字母 | 一个换行，随后正常字母 |
| 按住 Esc，再按 Enter | Delete，松开 Esc 后 Enter 恢复单次回车 |
| 按住 Space，再按 Enter | 反引号；松开 Space 后恢复回车 |
| GAME 中重复短按后长按 Enter（入口可用时） | 短按按次数回车，长按不继续回车 |

若仍漏响应或连击，先确认刷入的是本次 Actions 产物，并记录 USB / 蓝牙分别是否复现、是否仅发生在 Enter，以及唤醒后的第一键是否更容易漏。若单次物理按键在按键事件查看器里出现多组完整按下和松开事件，需要进一步检查开关抖动、焊点或扫描信号；本次没有盲目增加全键盘消抖时间。

## 10. 本次 Enter 调整

基础层 `&lt SYM RET`、游戏层 `&lt FUN RET` 改为 `&enter_lt SYM 0`、`&enter_lt FUN 0`。第二个参数 `0` 是未使用的占位参数，Enter 键码固定在 `enter_once` 宏中。

`enter_lt`：点按优先，300 毫秒，关闭快速点按强制判定和输入后空闲限制；长按调用 `&mo` 切层，短按调用 `enter_once`。`enter_once`：每次触发仅排入一对 Enter 按下 / 松开事件，按下保持 40 毫秒，释放后间隔 10 毫秒。单次宏不会随物理按住时间延长而持续按住 Enter。

原版 `&lt` 的快速点按机制本来就未启用，因此不能把本次症状直接归因于 `quick-tap-ms`；本次的主要防护是固定回车脉冲并自动释放。字母区修饰键、其他层键、扫描配置和休眠参数保持原有设置。
